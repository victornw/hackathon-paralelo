# Homologadoras B2B (vendem homologação/engenharia solar para integradores)

Data da pesquisa: 2026-11-07. Rótulos: **VERIFIED** = abri a página e li o trecho; **REPORTED** = só trecho de busca, não abri; **ESTIMATE** = estimativa de terceiro (nenhuma obtida, ver Lacunas); **INFERRED** = conta/dedução minha, sinalizada.

Registro (porte, capital, abertura, CNAE) vem da API pública BrasilAPI (`https://brasilapi.com.br/api/cnpj/v1/<CNPJ>`), que espelha dados da Receita Federal, consultada hoje. cnpja (HTTP 429), cnpj.biz (402), econodata (403) e LinkedIn (403) bloquearam o acesso, então **não obtive nenhuma "receita estimada" nem número de funcionários de site de dados**.

**Faixa legal de faturamento** = teto legal do enquadramento no registro (ME ≤ R$ 360 mil/ano; EPP ≤ R$ 4,8 mi/ano; MEI ≤ R$ 81 mil/ano). É teto da classificação, **não é faturamento real**.
